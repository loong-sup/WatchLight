# Watchlight 主工作台视觉与观测体验升级 Checklist

> 输入：已批准的 `spec.md`、`plan.md` 与 `task.md`

## 实现完整性

- [x] 浅色视觉体系能清晰区分背景、面板、卡片、交互控件和状态。（验证：打开主工作台观察层级）
- [x] 顶栏显示品牌、连接状态、会话数、运行状态、事件数和工具数。（验证：分别观察有活动运行和无活动运行）
- [x] 会话列表的刷新、选择、状态和长文本展示正常。（验证：点击刷新并切换会话）
- [x] 七层架构由连续光迹连接，四种状态同时有文字与形态差异。（验证：观察等待、活动、完成、失败 fixture 或实时事件）
- [ ] 输入、工具、输出、回写和事件在中间区域具有不同层级。（验证：打开包含工具调用的运行）
- [ ] 检查器可隐藏和恢复，最终输出、工具参数、结果及上下文仍可访问。（验证：切换检查器并操作内部控件）
- [ ] 消息输入保持发送、禁用和状态反馈行为。（验证：空输入与非空输入各操作一次）

## 可访问性与边界

- [ ] 所有按钮和输入框具有清晰的键盘焦点。（验证：仅用 Tab 键遍历交互控件）
- [ ] 状态信息不只依赖颜色。（验证：忽略颜色后仍可从图形或文字区分）
- [ ] 开启减少动态效果后光迹停止持续动画。（验证：模拟 `prefers-reduced-motion: reduce`）
- [ ] 长标题、长消息、长工具结果不会撑破所在面板。（验证：使用现有长内容或浏览器修改文本观察）

## 响应式

- [ ] 1440px 视口下三栏和顶部指标完整可用。（验证：浏览器设置 1440px 宽）
- [ ] 1024px 视口下主链路优先可读，检查器可按需显示。（验证：浏览器设置 1024px 宽）
- [ ] 768px 视口下内容可纵向访问且无页面级横向滚动。（验证：浏览器设置 768px 宽）
