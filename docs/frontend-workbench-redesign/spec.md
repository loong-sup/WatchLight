# Watchlight 主工作台视觉与观测体验升级 Spec

> 状态：草案，等待评审  
> 日期：2026-08-02  
> 范围：仅主工作台，不包含教学走读页

## 背景

Watchlight 主工作台已经能够展示实时会话、架构执行链路、对话与事件时间线、模型输出、工具调用和消息上下文。当前界面采用三栏控制台结构，功能信息完整，但大量模块使用相近的边框、字号和背景，导致视觉层级偏弱；运行状态主要依赖文字和小色点，执行过程缺少鲜明、连续的品牌表达；顶部也尚未把已有运行数据汇总成便于快速判断的观测指标。

第一轮升级以现代浅色运维台为基础，引入“光迹穿过执行链路”的 Watchlight 品牌元素，并使用前端现有运行数据补充基础观测指标。升级不得改变现有后端协议和核心业务流程。

## 目标

- 建立清晰、克制、适合长时间使用的浅色运维台视觉体系。
- 让用户能够快速识别当前连接状态、活动会话和执行所处阶段。
- 使用连续光迹表达消息从入口到回复的执行过程，形成 Watchlight 的品牌记忆点。
- 在不新增后端接口的前提下，展示第一批可计算的运行观测指标。
- 保留现有工作台功能，并改善常见桌面和窄屏尺寸下的使用体验。

## 功能需求

- F1：工作台必须采用统一的浅色视觉体系，建立明确的页面背景、面板、浮层、文字、边框、圆角、阴影和状态色层级。
- F2：顶部区域必须同时呈现 Watchlight 品牌、当前工作台语境、Gateway/WebSocket 连接状态和一组运行概览指标。
- F3：运行概览必须仅使用现有前端可获得的数据，至少展示会话总数、活动状态、事件数量和工具调用数量；没有活动会话时应显示稳定的空状态。
- F4：左侧会话列表必须强化当前选择、运行状态、通道、模型和更新时间的视觉层级，并保留刷新与切换会话能力。
- F5：架构执行链路必须使用连续“光迹”连接各阶段；等待、进行中、完成和失败状态必须同时通过颜色、形态和文字表达。
- F6：中间区域必须明确区分运行概览、用户输入、工具过程、模型输出、通道回写和底层事件，降低同层信息相互竞争的问题。
- F7：右侧检查器必须强化最终回复、工具结果和消息上下文的分组层级，并允许在较窄桌面尺寸下收起或隐藏，以优先保证主链路可读性。
- F8：消息输入区必须与新的视觉体系一致，并保持原有发送、禁用和发送状态反馈行为。
- F9：工作台必须提供自然但克制的状态动效；活动光迹可运动，完成和失败状态保持稳定，用户偏好减少动效时必须关闭非必要动画。
- F10：空数据、连接中断、运行失败和内容溢出场景必须保持可读，不得出现布局塌陷或仅靠颜色传达状态。

## 非功能需求

- N1：不新增 UI 框架或大型可视化依赖，优先使用现有 Vue、CSS 和浏览器能力。
- N2：不修改后端接口、WebSocket 事件格式或运行时数据结构；观测指标由现有状态派生。
- N3：核心工作区在 1440px 桌面宽度下完整显示；在 960px 至 1439px 之间仍能优先使用主链路；更窄尺寸下允许面板纵向重排。
- N4：所有正文、状态和交互控件必须具有足够对比度，键盘焦点清晰可见。
- N5：持续动画不得干扰内容阅读，并遵守系统的减少动态效果偏好。
- N6：长会话标题、长模型名称、长工具结果和长消息内容不得撑破布局。
- N7：第一轮改造应保持现有前端构建流程可用，不引入新的部署步骤。

## 不做的事

- 不改造 `walkthrough.html` 教学走读页。
- 不新增关注任务、调度管理或其他业务页面。
- 不新增后端指标接口、持久化统计或跨运行历史分析。
- 不实现可拖拽面板、用户自定义布局或完整仪表盘编辑器。
- 不在第一轮加入完整深色主题；只为后续主题扩展保留设计变量基础。
- 不改变消息发送、会话选择、工具详情和消息上下文的业务行为。

## 验收标准

- AC1：打开主工作台时，可以清楚区分页面背景、三块主要工作区、内容卡片和交互控件，页面不再依赖密集边框形成层级。（对应 F1）
- AC2：顶部可直接看到品牌、连接状态、会话数、当前运行状态、事件数和工具数；无活动会话时指标仍有明确含义。（对应 F2、F3）
- AC3：切换会话后，左侧选中态明显，中间链路和右侧详情同步更新，刷新与选择行为保持可用。（对应 F4）
- AC4：运行期间可观察到光迹推进至当前阶段；成功阶段、失败阶段和等待阶段不依赖颜色也能区分。（对应 F5、F9）
- AC5：用户输入、工具调用、模型输出、通道回写和原始事件具有不同且一致的视觉层级，长文本可换行或滚动而不破坏布局。（对应 F6、F10）
- AC6：最终回复、工具结果、调用参数和消息上下文仍可访问，较窄桌面尺寸下主链路不会被左右面板挤到不可读。（对应 F7）
- AC7：输入消息、禁用发送按钮、发送状态和聚焦状态均正常工作，且符合新的视觉样式。（对应 F8）
- AC8：在开启“减少动态效果”的系统环境中，光迹等非必要动画停止，但状态表达仍完整。（对应 F9、N5）
- AC9：在 1440px、1024px 和 768px 三种视口下，工作台没有横向页面溢出，关键内容均可访问。（对应 F10、N3、N6）
- AC10：前端类型检查和生产构建通过，运行时数据协议与后端无需修改。（对应 N1、N2、N7）

## 自检

- 无 TBD、TODO 或未完成小节。
- 需求描述不依赖具体组件名或实现方法。
- F1 至 F10 均有对应的可观测验收标准。
- 第一轮范围仅覆盖主工作台，可在单次实现周期内完成。
